# Marketplace Health Analytics

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on analyzing marketplace transaction data to understand sales performance, customer activity, order behaviour and overall marketplace health.

## Tools Used

- *Excel* – Data cleaning and data preparation
- *Python (Pandas, NumPy)* – Data analysis and metric calculation
- *Tableau* – Interactive dashboard and visualization
- *GitHub* – Project documentation

## Project Workflow

Raw Data → Excel Data Cleaning → Python Analysis → Tableau Dashboard → Business Insights

## Data Cleaning

The dataset was cleaned in *Microsoft Excel* by checking missing values, duplicate records, data types, invalid values and data consistency.

## Python Analysis

Python was used to calculate and analyze:

- Total Customers
- Total Orders
- Total Sales
- Total Quantity
- Average Transaction Value
- Monthly Marketplace Activity
- Customer Activity
- Category Performance
- Repeat Customer Analysis
- Top Customers and Orders

## Tableau Dashboard

The dashboard provides:

- Total Sales
- Total Orders
- Total Customers
- Average Transaction Value
- Monthly Sales Trend
- Sales by Category
- Orders by Category
- Customer Activity
- Quantity by Category

## Outcome

The project provides a clear view of marketplace transaction activity and helps identify sales trends, customer behaviour and category-level performance for better business decision-making.
